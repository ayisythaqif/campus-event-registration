# Campus Event Registration System

A web-based system that simplifies campus event discovery and registration for students while helping event organizers manage participants efficiently.

## Problem statement

Students, campus event organizers, and university administrators face challenges managing campus event registrations. Manual registration processes and scattered event information make it difficult for students to discover events and register easily. Organizers may experience duplicate registrations, inaccurate participant lists, and difficulties tracking attendance. A Campus Event Registration System is needed to centralize event information, simplify registration, and improve the overall management of campus events.
