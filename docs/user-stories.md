# User Stories

Format: As a [type of user], I want [goal], so that [reason or benefit].

## 1. Browse Upcoming Campus Events (FR2)

As a student, I want to browse upcoming campus events, so that I can find events that match my interests.

**Acceptance criteria:**
- The system shall display upcoming events with their names, dates, times, venues, and descriptions.
- The system shall allow students to view the full details of a selected event.

## 2. Register for an Event (FR3)

As a student, I want to register for an event online, so that I can reserve my place without completing manual paperwork.

**Acceptance criteria:**
- The system shall allow students to register for an event if places are available.
- The system shall display a confirmation message after successful registration.

## 3. View and Cancel Registrations (FR5)

As a student, I want to view and cancel my event registrations, so that I can manage my participation easily.

**Acceptance criteria:**
- The system shall display all events for which the student has registered.
- The system shall allow students to cancel registrations and update the registration records.

## 4. Manage Event Details (FR6)

As an event organizer, I want to create and update event details, so that students can access accurate and up-to-date information.

**Acceptance criteria:**
- The system shall allow organizers to create events by entering the required event details.
- The system shall allow organizers to update or delete existing events.

## 5. View Registered Participants (FR7)

As an event organizer, I want to view the list of registered participants, so that I can plan and prepare for the event.

**Acceptance criteria:**
- The system shall display the list of students registered for a selected event.
- The system shall update the participant list when a student registers or cancels a registration.

## 6. Monitor Campus Events (FR7)

As a university administrator, I want to monitor campus events and registration records, so that I can ensure events are managed effectively.

**Acceptance criteria:**
- The system shall allow administrators to view campus event details and registration totals.
- The system shall display the registration records for each event.

## 7. Receive Registration Confirmation (FR3)

As a student, I want to receive a confirmation notification after registering for an event, so that I know my registration was successful.

**Acceptance criteria:**
- The system shall display a confirmation notification after successful registration.
- The confirmation shall include the name and date of the registered event.
