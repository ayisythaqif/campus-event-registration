# User Stories

Format: As a [type of user], I want [goal], so that [reason or benefit].

1. As a student, I want to browse upcoming campus events, so that I can find events that match my interests.
2. As a student, I want to register for an event online, so that I can reserve my place without completing manual paperwork.
3. As a student, I want to view and cancel my event registrations, so that I can manage my participation easily.
4. As an event organizer, I want to create and update event details, so that students can access accurate and up-to-date information.
5. As an event organizer, I want to view the list of registered participants, so that I can plan and prepare for the event.
6. As a university administrator, I want to monitor campus events and registration records, so that I can ensure events are managed effectively.
