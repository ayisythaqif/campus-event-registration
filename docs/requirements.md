# Requirements

## Functional requirements (what the system must DO)

1. The system shall allow students to create an account and log in securely.
2. The system shall display a list of upcoming campus events with details such as event name, date, time, venue, and description.
3. The system shall allow students to register for available campus events.
4. The system shall prevent students from registering for the same event more than once.
5. The system shall allow students to view their registered events and cancel their registrations.
6. The system shall allow event organizers to create, update, and delete event information.
7. The system shall allow event organizers to view the list of registered participants for each event.

## Non-functional requirements (how the system must PERFORM)

1. The system shall load event listings and event details within 2 seconds under normal operating conditions.
2. The system shall protect user passwords and personal information using appropriate security measures.
3. The system shall be available at least 99% of the time during normal operating periods.
4. The system shall provide a responsive interface that works on desktops, tablets, and smartphones.
5. The system shall support at least 500 concurrent users without significant performance degradation.
