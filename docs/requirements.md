# Requirements

## Functional requirements

**FR1.** The system shall allow students to create an account and log in securely.

**FR2.** The system shall display upcoming campus events with their names, dates, times, venues, and descriptions.

**FR3.** The system shall allow students to register for available campus events.

**FR4.** The system shall prevent students from registering for the same event more than once.

**FR5.** The system shall allow students to view their registered events and cancel their registrations.

**FR6.** The system shall allow event organizers to create, update, and delete event information.

**FR7.** The system shall allow event organizers to view the list of registered participants for each event.

**FR8.** The system shall allow students to receive a confirmation notification after successful event registration.

## Non-functional requirements

**NFR1.** The system shall load event listings and event details within 2 seconds under normal operating conditions.

**NFR2.** The system shall protect user passwords and personal information using appropriate security measures.

**NFR3.** The system shall be available at least 99% of the time during normal operating periods.

**NFR4.** The system shall provide a responsive interface that works on desktops, tablets, and smartphones.

**NFR5.** The system shall support at least 500 concurrent users without significant performance degradation.
